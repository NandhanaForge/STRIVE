🔥 STRIVE

Skill Transformation, Resilience, Improvement, Victory, Excellence

A gamified placement-prep and job-readiness platform for engineering students — built as a single self-contained web app.

✨ Features
Onboarding — captures name, college, branch and year, then generates a personalised prep plan based on mood/motivation.
Dashboard — daily streak, recommended domain, mock score, and an XP/Level system that grows as you complete goals, quizzes and projects. Includes a skill-gap radar chart (DSA, Aptitude, SQL, Domain, Communication, Resume) and a daily goals checklist with badge unlocks.
Placements Tracker — upcoming drives with eligibility, countdown timers, a "targeting" toggle, and an expandable interview-pattern view per company.
Projects — a lightweight portfolio tracker to log and manage projects (title, tech stack, status).
Quiz — three categories: General Aptitude, Pre-Placement Basics (PPT/eligibility/process), and Domain Technical (questions tailored to the student's branch: ECE, CSE, IT, EEE, Mech, Civil). Includes a progress bar and a full answer review at the end.
Classes — short course recommendations curated per branch.
Senior Stories — real placement journeys, filterable by company or branch, with upvoting.
🛠️ Tech Stack
Plain HTML, CSS and JavaScript (no build step, no dependencies to install)
Chart.js (via CDN) for the skill radar chart
Browser localStorage for saving goals, XP, targeted placements and projects across visits
